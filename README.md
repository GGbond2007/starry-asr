# 星空语音识别引擎 (Starry ASR)

> 面向视障用户的 Android 语音识别输入法服务

## 简介

星空语音识别引擎是一款专为视障用户设计的 Android 语音识别服务应用。它通过系统 RecognitionService 接口提供语音输入能力，支持多种在线和离线识别引擎，可与任意输入法的语音输入按钮无缝集成。

## 核心特性

- **多引擎支持**：Whisper 离线、Sherpa-NCNN 离线、MSC（讯飞）在线、搜狗在线/离线
- **无障碍优先**：全面适配 TalkBack 屏幕阅读器，所有控件可朗读、可操作
- **大模型修正**：可选启用大模型对识别结果进行二次修正，支持深度思考模式
- **端点检测**：基于 Silero VAD 的语音活动检测，自动判断说话结束
- **多语言**：中文普通话、英语、粤语、四川话、东北话等多种方言
- **热词优化**：MSC 引擎支持自定义热词，提升专有名词识别率

## 系统要求

- Android 6.0 (API 23) 及以上
- arm64-v8a 架构

## 使用方式

1. 安装 APK
2. 系统设置 → 语言和输入法 → 语音输入 → 选择「星空语音识别引擎」
3. 在任意输入法中点击语音输入按钮即可使用
4. 打开应用可管理模型、切换引擎、调整设置

## 引擎对比

| 引擎 | 类型 | 需要联网 | 特点 |
|------|------|----------|------|
| Whisper | 离线 | 否 | 多语言，隐私优先，需要下载模型 |
| Sherpa-NCNN | 离线 | 否 | 轻量快速，基于 NCNN 推理框架 |
| MSC（讯飞） | 在线 | 是 | 中文效果最佳，支持方言和热词 |
| 搜狗在线 | 在线 | 是 | 短语音/长语音，支持多种语言 |
| 搜狗离线 | 离线 | 否 | 中文普通话，测试版 |

## 无障碍设计

- 模型管理页分组支持折叠/展开，TalkBack 朗读状态
- 下载进度更新不会导致屏幕阅读器焦点乱跳
- 设置页开关使用原生 Switch 控件，支持直接操作
- 底部标签页可正确朗读选中状态
